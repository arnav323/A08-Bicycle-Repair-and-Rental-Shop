# A08 Bicycle Repair and Rental Shop

A responsive website for a bicycle repair and rental shop, developed as part of the Web Designing assignment at Manav Rachna University.

## Project Overview

The purpose of this project is to create a website for a bicycle repair and rental shop that currently has no online presence.

The website allows users to explore bicycle services, view prices, calculate rental costs, and submit enquiries.

### 1. Home Page
- Introduction to the bicycle shop.
- Overview of services.
- Bicycle rental calculator.

### 2. Services Page
- Bicycle repair and maintenance services.
- Service price list.
- Customer enquiry form.

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Bicycle rental price calculator.
- Enquiry form with validation.
- Phone number validation.
- Date validation to prevent past dates.
- JavaScript DOM updates.
- Local Storage for saving enquiry information.
- CSS transitions and responsive layouts.

**Note:** Enquiry information is stored in the user's browser using Local Storage. The form does not send information to a backend server.

## Rental Calculator

The rental calculator estimates the total rental cost using the selected bicycle's daily rental price and the number of rental days.

**Formula:**

Total Rental Price = Daily Rental Price × Number of Days

The calculator validates the entered values and displays the calculated amount on the page.
